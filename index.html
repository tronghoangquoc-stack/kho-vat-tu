📖 HƯỚNG DẪN CÀI ĐẶT FIREBASE (1 LẦN DUY NHẤT)

Bước 1: Vào console.firebase.google.com → Tạo project mới (miễn phí)
Bước 2: Vào Build → Realtime Database → Create database → chọn Start in test mode
Bước 3: Vào Project Settings → General → Thêm Web App → Copy firebaseConfig
Bước 4: Mở file HTML này bằng Notepad, tìm dòng FIREBASE_CONFIG_HERE và thay bằng config vừa copy
Bước 5: Upload file HTML lên pages.github.com hoặc netlify.com (miễn phí) để có link dùng online
